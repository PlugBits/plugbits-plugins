## 確定した知見

1. **OCR形状カテゴリは判別力ゼロ**（全候補が同カテゴリ一致で定数+0.08の下駄になっていた）→ SCORE_SHAPE_CATEGORY_BONUS=0 で無効化を仮採用
2. **支配的な失敗モード＝「同種部品の見た目似・別物」**。×候補の大半がクエリとAI形状タグを共有（フランジ同士・円筒部品同士等）。タグの語彙は部品種レベルで、同種内の別物を区別できない
3. **shapeTagペナルティの発動精度は低い**: dev25で発動15件中 ○6/×9（4割が誤爆）。0.1のまま維持、強化はしない（termDiagnostics で判断）
4. **メタデータ（材質・品名等）は現データではほぼ無効**: 一致がほぼ発生しない or 一致しても別物（productName match の×が複数）
5. **順位は実質ベクトル単独**で決まっており、クエリ内で○×を分離できないケースが多い（×のvectorRawが○より高い例が頻出）
6. **取りこぼしの実例**: query 3533 の類似 811（判定者認定）が検索上位10件圏外（vector類似 <0.911）。埋め込みレベルのミス。ランダム25本中1件の検出
7. **「類似が存在しない」クエリ**も実在（例: 2169。top vectorRaw 0.95・全滅）。有用率の分母には含める（実運用の正直な数字とするため）
